# YAMSHI Pixels

Unlimited Meta pixels + Conversion API for Shopify. Adding a pixel never replaces existing ones.

**Price: 15 days free, then $4.99/month or $45/year**

## Local
```
cp .env.example .env
npm install
npm run dev
```

## Shopify
```
npx shopify app deploy
```
Then install on the store: Admin → Apps.
